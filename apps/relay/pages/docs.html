API reference

Base URL is this host. Send JSON. Send the bearer token from login on every route that asks for a session.

Route list

  • POST /auth/login {"user","pass"}
  • GET /api/notes/:id
  • POST /api/profile
  • POST /graphql
  • POST /api/merge
  • GET /health

Login

POST /auth/login with a JSON body of user and pass. A matching account returns { "token" }.

curl -s -X POST "$ORIGIN/auth/login" \
  -H "content-type: application/json" \
  -d '{"user":"YOUR_USER","pass":"YOUR_PASS"}'

Notes

GET /api/notes/:id with Authorization: Bearer TOKEN. The body is the note stored for that id. /api/notes/2 is the shape, and it expects a session.

Profile

POST /api/profile with the bearer token and a JSON object. Fields you send are copied onto the profile returned to you.

GraphQL

POST /graphql with a JSON body whose query field is the document you want to run.

curl -s -X POST "$ORIGIN/graphql" \
  -H "content-type: application/json" \
  -d '{"query":"{ ... }"}'

Merge

POST /api/merge with a JSON object. Nested objects are folded into the working document and the result is returned.

Health

GET /health returns { "ok": true } for the checker.
