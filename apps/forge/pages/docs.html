Line reference

JSON for the posts. Query strings for the reads. Base URL is this host.

  • POST /hooks/test {url}
  • POST /jobs
  • GET /jobs/{id}
  • GET /template?name=
  • GET /download?f=

Hook test

POST /hooks/test with { "url": "https://..." }. The forge fetches that address and returns the first part of the body as text.

curl -s -X POST "$ORIGIN/hooks/test" \
  -H "content-type: application/json" \
  -d '{"url":"https://example.com"}'

Jobs

POST /jobs with cmd and owner. The response includes the new id and a pending status. GET /jobs/{id} returns that record.

Template

GET /template?name=world renders a greeting from the name query. The home form submits the same field.

Download

GET /download?f= returns a file from the jobs directory. The query name is f.
