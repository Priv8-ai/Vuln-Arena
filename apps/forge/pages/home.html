Pipelines that start when a webhook lands.

Foundry CI is the job runner for plants that already fire a hook: queue a run, render its name, and pull the file it left behind.

Render a job name Read the routes
1. HookA caller posts the URL the forge should fetch.
2. JobThe run is queued with a command and an owner.
3. NameA template renders the greeting on the job.
4. FileDownload pulls the artifact the run stored.
