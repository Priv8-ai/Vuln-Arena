Board reference

The home board loads the client script and its map, then calls these routes.

  • POST /api/settings
  • GET /render?tpl=
  • GET /pick?file=
  • POST /api/import

Settings

POST /api/settings with a JSON object. The title you store is the heading on the home board.

curl -s -X POST "$ORIGIN/api/settings" \
  -H "content-type: application/json" \
  -d '{"title":"Studio wall"}'

Render

GET /render?tpl=Hello renders the tpl string with the current config in scope. The home form submits that query.

Files

GET /pick?file=readme.txt returns a file stored with the board. The default name, when you omit the query, is readme.txt.

Import

POST /api/import with a JSON body when a producer delivers the deck that way.

Scripts

The board shell includes /static/board.js and /static/board.js.map.
