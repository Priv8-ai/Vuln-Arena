The board is the room.

Kiteboard keeps four things within reach: the board’s settings, a template render, a file pick, and an import when a deck arrives as JSON.

Settings

POST /api/settings stores the board title and any other fields the studio sends. The home heading reads that title back.

Templates

GET /render?tpl= turns the template string into the preview line. The form on the home board posts there.

Files and import

GET /pick?file= reads a file that lives with the board. POST /api/import accepts the JSON a producer hands over.
