How a critique actually runs

Four moves, in the order a producer uses them. This is a sequence, so it is numbered.

  1. Name the wall. Send the title with POST /api/settings. The home heading picks it up.
  2. Put the reference on the board. Open readme.txt, or pass another file name the studio stored.
  3. Render the line you will pin. Preview Hello, or use the template field on the home board.
  4. Import the deck. POST /api/import when a producer delivers the work as JSON instead of a file.
