How the floor is wired

Four surfaces. The socket carries the live notes. The other three are ordinary HTTP.

Channel

Connect to /ws on this host. Send a text frame. Every open client receives that text, and the home floor paints it into the log.

const ws = new WebSocket((location.protocol === "https:" ? "wss" : "ws") + "://" + location.host + "/ws");
ws.send("handoff complete");

History

GET /history returns the transcript as a JSON array, oldest first.

Reports

GET /report is the form. POST the same path with a body field (or JSON message). The response is { "ok": true, "id": n }.

Mod bot

GET /mod is the queue. Each stored report is shown in order.
